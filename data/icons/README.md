# Bundled icons

`kaint-breeze/` and `kaint-breeze-dark/` hold the icons from KDE's
[Breeze icon theme](https://invent.kde.org/frameworks/breeze-icons) that Kaint uses, so menus and
buttons have icons on Windows and on Linux systems without Breeze. Kaint prefers the system
Breeze theme when it is installed.
