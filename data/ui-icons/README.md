# Interface icons

The PNG icons in this folder (tools, menus, the Layers and History windows, tool options,
adjustments, effects and settings pages) come from SSSerch's fork of
[paint.js](https://github.com/LabyStudio/paintdotjs) and are used in Kaint with their author's
permission. Kaint scales them to the size it needs and turns them gray when an option is disabled.

The tool icons that show the active colors (Paintbrush, Paint Bucket, Recolor and Gradient) and
the Pan tool hand are still drawn in code (`src/app/PdnIcons.cpp`).
